# Depop Partner API Access Request

**To:** business@depop.com
**Subject:** Partner API Access Request — Listd (AI Listing Tool for Depop Sellers)

---

Hi Depop team,

I'm building **Listd** — an AI-powered listing assistant that helps Depop sellers create better listings faster. Sellers upload photos of a clothing item and the app analyses the photos, identifies the brand and garment details, reads care labels, and generates a complete, platform-optimised listing (title, description, suggested price, and hashtags) in seconds.

The app also coaches sellers on their photos before generating — telling them which shots are missing (back view, tag photo, defect close-up) and giving specific suggestions to improve their listing quality. The goal is to help sellers, especially casual ones clearing their wardrobes, list with confidence rather than skipping fields or writing lazy descriptions that don't sell.

I've reviewed the Depop Partner API documentation and I'm specifically interested in the OAuth 2.0 (Authorization Code + PKCE) integration, which would allow individual Depop sellers to connect their accounts and post directly from Listd. I've noted that Depop's Terms of Service explicitly permit third-party crosslisting, and I want to build a product that's fully compliant and works with your platform rather than around it.

**What I'm asking for:**
- Access to the Depop Partner API (sandbox environment to start)
- OAuth 2.0 client credentials so individual sellers can connect their Depop accounts
- Guidance on which product categories and attribute fields to map to

**What I can offer:**
- A product that drives higher-quality listings to Depop — better descriptions, better photos, better discoverability
- A user base of casual sellers who currently find listing too tedious to do well
- Full compliance with Depop's Terms of Service, seller guidelines, and photo standards

I'm happy to share more detail about Listd, sign any required agreements, and work within whatever approval process you have. I'm also happy to discuss how Listd can be built to complement Depop's own AI listing features rather than duplicate them.

Would you be able to point me to the right person or process for partner API access?

Thanks for building such a great platform — excited about what we could do together.
